1. Коммит - это фиксация изменений (снимок проекта), ветка — указатель на цепочку коммитов, чтобы вести параллельную разработку.

2. git add подготавливает изменения для коммита (кладёт в индекс), git commit их фиксирует.

3. Флаг -b в git checkout -b создаёт новую ветку и сразу переключается на неё.

4. Pull Request нужен для проверки и обсуждения кода перед вливанием в основную ветку - чтобы не пропустить ошибки и соблюсти стандарты.

5. После merge ветка остаётся - её обычно удаляют вручную, если больше не нужна.
